# Unruly

An educational phone game from the IDEMS game studio, based on
*Unruly* (also known as Takuzu or Binairo) from
[Simon Tatham's Portable Puzzle Collection](https://www.chiark.greenend.org.uk/~sgtatham/puzzles/).

Fill the grid with black and white squares: no three of the same colour
in a row or column, and every row and column has as many of each colour.

Work in progress: the app is being built from the Rectangles scaffold.
